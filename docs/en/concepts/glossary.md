# Glossary

| Term | Meaning |
|---|---|
| **`prci`** | The compiled binary name, `cmd/prci-gui`. Running it opens the GUI window directly — no command-line arguments are parsed. `perci` is installed alongside it as a symlink alias — both are interchangeable. |
| **Category** | One of the six top-level GUI sidebar sections: Home, Linux, Desenvolvimento, Docker, Repositórios, Dev Tools. Each maps to a `MenuCategory` value in `cmd/prci-gui/catalog.go`. |
| **Action** | A single menu entry inside a category (e.g. "Gerenciar Fontes"), backed by a `MenuItem.ActionID` wired to a Go method (bound to the GUI's frontend) that calls a domain function. |
| **Distro family** | The Debian or Fedora lineage a distro belongs to, as detected by `internal/distro`. Post-install and package-manager logic branches on family, not on the specific distro name. Arch is not a supported family. |
| **Workspace** | The root folder (`workspace_path` in config) under which projects and the per-project Docker application stack's `localhost/*` folders live. |
| **Container Aplicativo** | One project's own Docker container — its own `*.localhost` URL, PHP and/or Node version, isolated `html`/`data` folders. The unit the Docker application stack manages; see [Docker application stack architecture](../architecture/appstack.md). |
| **Moodle install** | A `Container Aplicativo` of type `moodle` — its own dedicated container/vhost, not a shared routing entry among several installs. |
| **AI Context** | Generated context files that teach AI coding agents a target project's conventions: `AGENTS.md`, `.instructions/*.md` and, per checked agent, `CLAUDE.md`, `.claude/rules/perci/*.md`, `.claude/settings.json`, `GEMINI.md`, `.aiexclude`, `.geminiignore` or `opencode.json` entries. Generated by `internal/manager/ai`, called directly from the GUI's "Dev Tools :: IA: Contextos" screen, which also keeps the list of folders that have one (`ai_contexts`). |
| **Project rules** | `.instructions/PROJECT.md`: the rules defined for one project, which agents write there when the user sets them. Created once by IA: Contextos and never rewritten; it overrides `AGENTS.md` and the standards. |
| **AI Skill** | A standalone `SKILL.md` file teaching a coding agent a specific working mode (e.g. "Frontend Design"). GUI-only, "Dev Tools :: IA: SKILLs" (`internal/dev/agentskills`): installs third-party skills from [skills.sh](https://www.skills.sh/) via `npx skills add/remove/update`, targeting Claude Code/OpenCode/Antigravity/Codex. A sibling concept to AI Context and MCP servers, not a submenu of either. (`internal/manager/skills`/`prci skills` — Perci's own bundled skills, e.g. "Claude Code Mode" — was removed 2026-09-11 in favor of this broader catalog.) |
| **MCP Server** | A Model Context Protocol server giving a coding agent extra tools (e.g. filesystem access, library documentation, a database). GUI-only, "Dev Tools :: IA: MCPs" (`internal/dev/mcpservers`): registers one with Claude Code/Codex (their own `mcp`/`plugin` CLI subcommands) and Antigravity (direct `mcp_config.json` edit) — each agent has its own mechanism, unlike the single `npx skills` tool AI Skill uses. |
| **Git account** | A GitHub or GitLab user registered in **Repositórios → Configurar Conta** (`git_accounts` in config). It owns a folder: every repository inside uses the account's commit identity and SSH key through an `includeIf` rule in `~/.gitconfig`. Backed by `internal/manager/gitaccount`. |
| **Pending repository** | A repository imported by **Gerenciar Repositórios → Importar** and not cloned yet; listed on its account's screen until **Clonar pendentes** clones it or **Descartar** drops it. |
| **Executor** | `internal/executor.Executor`, the single point through which every privileged (`sudo`) command runs. Domain packages never call `sudo` directly. |
| **DE** | Desktop Environment (e.g. `cinnamon`, `xfce`, `gnome`), used together with distro to decide which post-install menu entry is enabled. |
