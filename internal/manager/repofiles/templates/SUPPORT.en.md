# Support

🌐 **Language:** English · [Português](docs/pt-br/suporte.md)

This page explains how to get help with {{PROJECT}}.

## Before asking

- Read the project's README and documentation.
- Search the {{ISSUES}}, including closed issues: your question may already have an answer.

## Questions and bug reports

Open an issue in the {{ISSUES}}. For a bug, use the bug report template and include:

- the version you are using;
- your operating system and environment;
- the steps to reproduce the problem;
- what you expected to happen and what happened instead;
- relevant logs or error messages, with personal data removed.

## Feature requests

Open an issue with the feature request template. Describe the problem you want to solve before the solution you have in mind.

## Private contact

For matters that should not be public, write to {{CONTACT_EMAIL}}. Do not report security vulnerabilities in public issues; send them to this address instead.

## Response times

This project is maintained on a best-effort basis. There is no guaranteed response time, but every report is read.
