# Suporte

🌐 **Idioma:** [English](../../SUPPORT.md) · Português

Esta página explica como obter ajuda com o {{PROJECT}}.

## Antes de perguntar

- Leia o README e a documentação do projeto.
- Procure no {{ISSUES}}, inclusive nas issues fechadas: sua dúvida pode já ter resposta.

## Dúvidas e relatos de bugs

Abra uma issue no {{ISSUES}}. Para um bug, use o modelo de relato de bug e inclua:

- a versão que você usa;
- seu sistema operacional e ambiente;
- os passos para reproduzir o problema;
- o que você esperava que acontecesse e o que aconteceu;
- logs ou mensagens de erro relevantes, sem dados pessoais.

## Pedidos de recurso

Abra uma issue com o modelo de pedido de recurso. Descreva o problema que você quer resolver antes da solução que imagina.

## Contato privado

Para assuntos que não devem ser públicos, escreva para {{CONTACT_EMAIL}}. Não relate vulnerabilidades de segurança em issues públicas; envie-as para este endereço.

## Prazos de resposta

Este projeto é mantido conforme a disponibilidade. Não há prazo garantido de resposta, mas todo relato é lido.
